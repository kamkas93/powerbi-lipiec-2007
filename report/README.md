Plik raportu `.pbix` (Power BI Desktop, tryb Import) jest do pobrania z wydania **[v1.0](https://github.com/kamkas93/powerbi-lipiec-2007/releases/tag/v1.0)**.

Pliki `*.pbix` są w `.gitignore` i nie trafiają do commitów repozytorium.
